## Installation

### Windows

Run `Nebulae-Setup-x64.exe`. No extra steps.

### macOS

Open the dmg and follow the three steps in `READ ME FIRST.txt` (also at
[INSTALL-macOS.md](INSTALL-macOS.md)):

1. Drag Nebulae to Applications.
2. Open it, click **Done** on the Apple warning.
3. System Settings > Privacy & Security > **Open Anyway**.

Steps 2 and 3 are only needed the first launch.

### Linux

Install the `.deb` or `.rpm`, or unpack the AppImage.
